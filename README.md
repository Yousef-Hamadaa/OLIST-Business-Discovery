## Project Overview

This project is part of the **Machine Learning Capstone on E-Commerce**. The project uses the Olist Brazilian E-Commerce dataset to explore customer, order, product, payment, delivery, seller, and review data.

Our target of this task is **Customer Rating Prediction**, a regression problem that predicts the customer review score on a scale from 1 to 5.

The project follows the capstone workflow of data loading, data quality auditing, cleaning, feature engineering, exploratory data analysis, preprocessing, model comparison, hyperparameter tuning, evaluation, and business interpretation.

## Selected Model Task

### Customer Rating Prediction — Regression

**Target variable:**

- `review_score` — customer rating from 1 to 5

**Main features used in the final Model 3 dataset:**

- `delivery_delay`
- `product_category_name_english`
- `seller_state_proxy`
- `payment_type`
- `avg_item_price`
- `freight_value`

Because the Olist dataset does not provide a direct courier/carrier identifier or a dedicated sales-channel field, `seller_state_proxy` and `payment_type` are used as dataset-specific proxies and are documented in the notebook.

## Dataset

The project uses the following Olist CSV files:

- `olist_customers_dataset.csv`
- `olist_geolocation_dataset.csv`
- `olist_orders_dataset.csv`
- `olist_order_items_dataset.csv`
- `olist_order_payments_dataset.csv`
- `olist_order_reviews_dataset.csv`
- `olist_products_dataset.csv`
- `olist_sellers_dataset.csv`
- `product_category_name_translation.csv`

The notebook combines the relevant datasets into a master DataFrame and creates derived features for analysis and modeling.

## Machine Learning Workflow

1. Load and inspect the raw datasets.
2. Audit data quality, missing values, duplicates, and data types.
3. Clean and validate the data.
4. Merge the Olist datasets into a master dataset.
5. Engineer delivery, revenue, and temporal features from available data.
6. Perform exploratory data analysis.
7. Build the Model 3 dataset and remove rows with missing ratings.
8. Split the data into training and testing sets.
9. Encode categorical features using `OneHotEncoder` and scale numerical features using `StandardScaler`.
10. Compare four regression algorithms.
11. Tune the best-performing model using `GridSearchCV`.
12. Evaluate the final model using MAE, RMSE, and R-squared.
13. Analyze prediction errors and feature importance.

## Algorithms

The following regression algorithms are compared:

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- K-Nearest Neighbors (KNN) Regressor

The best-performing algorithm is then tuned with `GridSearchCV` as required by the project specification.

## Evaluation

The final regression models are evaluated using:

- **MAE (Mean Absolute Error)**
- **RMSE (Root Mean Squared Error)**
- **R-squared (R²)**

The notebook also includes:

- Predicted vs. Actual rating plot
- Residual plot
- Mean Absolute Error by product category
- Feature importance analysis for the tuned Random Forest model
